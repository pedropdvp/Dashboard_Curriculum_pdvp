# Dashboard_Curriculum_pdvp

Interactive, animated CV dashboard (in English) of **Pedro Varela Pinto**, built from the Notion page
"Curriculum Pedro Varela Pinto" with all its certificates, documents, images and videos.

- Live: https://pedropdvp.github.io/Dashboard_Curriculum_pdvp/
- Content: `notion/*/_page.md` + downloaded files; `python3 tools/build_data.py` regenerates `data.js`.
